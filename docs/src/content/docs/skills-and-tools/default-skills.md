---
title: Default Skills
description: The skills that ship with every GHOST workspace.
---

GHOST installs these skills into `$WORKSPACE/skills/` when you run `ghost init`. They
cover the most common workflows out of the box.

## research

Multi-source web research for recommendations, comparisons, and buying decisions. Teaches
GHOST to search broadly, read full pages, compare sources, and cite its findings.

## knowledge-navigator

Querying the knowledge base effectively. Covers search strategies (keyword vs semantic),
graph traversal, tag browsing, and how to combine multiple queries to find what you need.

## note-writer

Creating structured knowledge notes following the note archetype system. Covers when to
use each archetype, how to write wiki links, how to set trust levels, and how to cite
sources.

## cron-job-author

Creating and improving cron-scheduled agent jobs. Teaches GHOST the `crontab.lua` format,
scheduling patterns, and best practices for background automation.

## skill-creator

Meta-skill: creating new skills. When your GHOST identifies a repeating workflow, it can
use this skill to formalize it into a reusable skill file.
