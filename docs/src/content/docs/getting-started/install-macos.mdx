## Quick Install

Run this single command in your terminal:

```bash
curl -sSf https://raw.githubusercontent.com/mrtolkien/ghost/main/deploy/macos/install.sh | sh
```

The script will:

<Steps>

1. Install [Nix](https://nixos.org/) if not already present.

2. Install all dependencies via Nix: llama.cpp, docling-serve, Docker CLI, and
   [Colima](https://github.com/abiosoft/colima) (if Docker Desktop is not
   installed).

3. Download the embedding model (Qwen3 Embedding 8B, ~8 GB).

4. Register and start native GPU services via launchd (llama-server on port
   11434, docling-serve on port 5001).

5. Walk you through an interactive setup wizard — select your LLM provider,
   enter API keys, configure Discord.

6. Start GHOST and companion services (Crawl4AI, SearXNG) via Docker Compose.

</Steps>

The install is idempotent — safe to re-run if interrupted.

## Architecture

```
macOS native (launchd, Metal GPU)
  llama-server :11434  — embeddings
  docling-serve :5001  — PDF processing

Docker (Desktop or Colima)
  ghost         — main daemon
  crawl4ai      — web extraction
  searxng       — web search
```

Docker containers reach host services via `host.docker.internal`.

## After Installation

Config files are at `~/.config/ghost/`:

- `config.toml` — model, provider, Discord settings
- `.env` — API keys and tokens
- `docker-compose.yml` — container configuration
- `searxng-settings.yml` — search engine configuration

Service logs are at `~/.local/share/ghost/logs/`.

### Managing Services

```bash
# Stop Docker services
docker compose -f ~/.config/ghost/docker-compose.yml down

# Restart Docker services
docker compose -f ~/.config/ghost/docker-compose.yml up -d

# Check native services
launchctl print gui/$(id -u)/com.ghost.llama-server
launchctl print gui/$(id -u)/com.ghost.docling-serve
```

### Changing Settings

Use the CLI after install:

```bash
ghost config set models.primary.model "anthropic/claude-sonnet-4"
```

Or edit `~/.config/ghost/config.toml` directly.
