## Prerequisites

Install [Nix](https://nixos.org/) if you don't have it:

```bash
curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install
```

## Binary Cache (recommended)

:::note
Once GHOST lands in nixpkgs, the binary cache will no longer be needed — Nix will fetch
pre-built binaries from the official cache automatically.
:::

Adding the GHOST binary cache avoids a ~15 minute compile from source.

If you installed Nix with the
[Determinate Systems installer](https://install.determinate.systems/nix)
(recommended), add to `/etc/nix/nix.custom.conf`:

```bash
echo 'extra-substituters = https://ghost-ai.cachix.org' | sudo tee -a /etc/nix/nix.custom.conf
echo 'extra-trusted-public-keys = ghost-ai.cachix.org-1:c0BYnkFKE8rYzkusZD5+l5D5Vcl8WRQMXV1zVWjxCBI=' | sudo tee -a /etc/nix/nix.custom.conf
sudo systemctl restart nix-daemon   # Linux
# macOS: sudo launchctl kickstart -k system/org.nixos.nix-daemon
```

<details>
<summary>Standard Nix (non-Determinate)</summary>

If you installed Nix via the official installer, use `/etc/nix/nix.conf`
instead of `nix.custom.conf`.

</details>

<details>
<summary>NixOS</summary>

Add the cache to your system configuration:

```nix title="configuration.nix"
nix.settings = {
  extra-substituters = [ "https://ghost-ai.cachix.org" ];
  extra-trusted-public-keys = [
    "ghost-ai.cachix.org-1:c0BYnkFKE8rYzkusZD5+l5D5Vcl8WRQMXV1zVWjxCBI="
  ];
};
```

</details>

## Install and Run

<Steps>

1. **Install GHOST**

   ```bash
   nix profile add github:mrtolkien/GHOST/latest
   ```

2. **Run the onboarding wizard**

   ```bash
   ghost init
   ```

   The wizard configures your LLM provider, Discord bot, and all services. See
   [Onboarding](/getting-started/onboarding/) for details.

</Steps>

## Install Channels

| Command                                         | What you get                  |
| ----------------------------------------------- | ----------------------------- |
| `nix profile add github:mrtolkien/GHOST/latest` | Latest release (recommended)  |
| `nix profile add github:mrtolkien/GHOST/main`   | Bleeding edge (latest commit) |
| `nix profile add github:mrtolkien/GHOST/v0.5.0` | Pinned version                |

## Updating

```bash
ghost update
```

## From Source

For development or manual setups, clone and build with Nix:

```bash
git clone https://github.com/mrtolkien/ghost.git
cd ghost
nix build
./result/bin/ghost version
```

Or install directly into your profile from a local checkout:

```bash
nix profile install .
```
