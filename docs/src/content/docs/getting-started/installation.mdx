## Prerequisites

- **Docker** with Docker Compose — [docs.docker.com](https://docs.docker.com/get-docker/)
- **Discord bot token** — for the Discord interface (see
  [Interfaces](/ghost/interfaces/))
- **API key** for at least one LLM provider (OpenRouter, Kimi, etc.)

## Setup

<Steps>

1. **Get the compose file**

   ```bash
   git clone https://github.com/mrtolkien/ghost.git
   cd ghost
   ```

   Or just download `docker-compose.yml` and `docker/searxng-settings.yml`.

2. **Configure secrets**

   Create a `.env` file in the project root:

   ```bash title=".env"
   # Required: at least one LLM provider
   OPENROUTER_API_KEY=sk-or-...

   # Required: Discord bot
   DISCORD_TOKEN=...

   # Optional: Brave web search (used if SearXNG is not running)
   BRAVE_API_KEY=BSA...
   ```

3. **Start all services**

   ```bash
   docker compose up -d
   ```

   This starts GHOST, Crawl4AI (web extraction), and SearXNG (web search).
   GHOST auto-detects the companion services via container networking.

4. **Configure (optional)**

   Most settings work out of the box with env vars. For advanced
   configuration, create `~/.config/ghost/config.toml`:

   ```toml title="~/.config/ghost/config.toml"
   [discord]
   allowed_user_id = "your-discord-user-id"

   [models.primary]
   provider = "openrouter"
   model = "anthropic/claude-sonnet-4"
   context_window = 200000
   ```

</Steps>

## Workspace

GHOST stores its data in `~/GHOST/` by default (bind-mounted into the
container at `/workspace`). This includes identity files, notes, skills,
agents, and the Nix shell flake.

## Shell Tools

The Docker image uses Nix to manage CLI tools deterministically. The default
set (git, ripgrep, fd, jq, curl, etc.) is pre-installed. GHOST can add tools
at runtime by editing `shell/flake.nix` in the workspace — changes take
effect on the next command, no restart needed.

## Building locally

For development, use the local build override:

```bash
docker compose -f docker-compose.yml -f docker-compose.local.yml up --build
```
