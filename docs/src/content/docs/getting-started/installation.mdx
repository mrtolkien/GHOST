## Quick Install (macOS)

Run this single command in your terminal:

```bash
curl -sSf https://raw.githubusercontent.com/mrtolkien/ghost/main/deploy/macos/install.sh | sh
```

The script will:

1. Install [Nix](https://nixos.org/) (if not already present)
2. Install all dependencies via Nix (llama.cpp, docling-serve, Docker, etc.)
3. Set up [Colima](https://github.com/abiosoft/colima) as a Docker runtime (if
   Docker Desktop is not installed)
4. Download the embedding model (Qwen3 Embedding 8B)
5. Start GPU-accelerated services natively (llama-server, docling-serve)
6. Walk you through an interactive setup wizard
7. Start GHOST and companion services via Docker Compose

### What you'll need ready

- A **Discord bot token** — see [Interfaces](/ghost/interfaces/)
- An **API key** for your LLM provider (OpenRouter, Kimi, etc.)

The setup wizard will prompt you for these.

## Architecture

GHOST runs as a hybrid stack on macOS:

- **Native (Metal GPU):** llama-server (embeddings) and docling-serve (PDF
  processing) run directly on macOS for GPU acceleration.
- **Docker:** GHOST, Crawl4AI (web extraction), and SearXNG (web search) run as
  containers.

## After Installation

<Steps>

1. **Config files** are at `~/.config/ghost/`:
   - `config.toml` — model, provider, Discord settings
   - `.env` — API keys and tokens
   - `docker-compose.yml` — container configuration

2. **Manage Docker services:**

   ```bash
   # Stop
   docker compose -f ~/.config/ghost/docker-compose.yml down
   # Restart
   docker compose -f ~/.config/ghost/docker-compose.yml up -d
   ```

3. **Change settings** after install with the CLI:

   ```bash
   ghost config set models.primary.model "anthropic/claude-sonnet-4"
   ```

</Steps>

## Workspace

GHOST stores its data in `~/GHOST/` by default (bind-mounted into the container
at `/workspace`). This includes identity files, notes, skills, agents, and the
Nix shell flake.

## Shell Tools

The Docker image uses Nix to manage CLI tools deterministically. The default set
(git, ripgrep, fd, jq, curl, etc.) is pre-installed. GHOST can add tools at
runtime by editing `shell/flake.nix` in the workspace — changes take effect on
the next command, no restart needed.

## Development Setup

For working on GHOST itself, clone the repo and use the dev compose files:

```bash
git clone https://github.com/mrtolkien/ghost.git
cd ghost
docker compose -f docker-compose.yml -f docker-compose.local.yml up --build
```
