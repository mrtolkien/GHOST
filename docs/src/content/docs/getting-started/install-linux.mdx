---
title: Linux Installation
description: Install GHOST on Linux.
---

:::caution
Linux installation is a work in progress. A one-command installer (similar to the
[macOS installer](/ghost/getting-started/install-macos/)) is planned but not yet
available.
:::

In the meantime, you can run GHOST on Linux using the
[source installation](/ghost/getting-started/install-source/) method.

The Linux installer will use systemd instead of launchd for native services, but
the overall architecture is the same — GPU services run natively, everything else
runs in Docker.
