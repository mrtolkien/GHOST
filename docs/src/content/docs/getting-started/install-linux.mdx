## Prerequisites

- [Nix](https://nixos.org/) package manager — install with
  [the Determinate Systems installer](https://install.determinate.systems/nix)

## Install GHOST

<Steps>

1. **Add the GHOST binary cache** (one-time setup, avoids compiling from
   source):

   ```bash
   echo 'extra-substituters = https://ghost-ai.cachix.org' | sudo tee -a /etc/nix/nix.conf
   echo 'extra-trusted-public-keys = ghost-ai.cachix.org-1:c0BYnkFKE8rYzkusZD5+l5D5Vcl8WRQMXV1zVWjxCBI=' | sudo tee -a /etc/nix/nix.conf
   sudo systemctl restart nix-daemon
   ```

2. **Install GHOST**

   ```bash
   nix profile add github:mrtolkien/GHOST/latest
   ```

   This downloads a pre-built binary (~20 MB) and installs it in your Nix
   profile. Without the binary cache, Nix would compile from source (~15
   minutes).

3. **Verify the installation**

   ```bash
   ghost version
   ```

</Steps>

## Updating

```bash
ghost update
```

This runs `nix profile upgrade` under the hood, fetching the latest cached
binary.

## Install Channels

| Command | What you get |
| --- | --- |
| `nix profile add github:mrtolkien/GHOST/latest` | Latest release (recommended) |
| `nix profile add github:mrtolkien/GHOST/main` | Bleeding edge (latest commit) |
| `nix profile add github:mrtolkien/GHOST/v0.5.0` | Pinned version |

## NixOS

On NixOS, add the binary cache to your system configuration instead:

```nix title="configuration.nix"
nix.settings = {
  extra-substituters = [ "https://ghost-ai.cachix.org" ];
  extra-trusted-public-keys = [
    "ghost-ai.cachix.org-1:c0BYnkFKE8rYzkusZD5+l5D5Vcl8WRQMXV1zVWjxCBI="
  ];
};
```
