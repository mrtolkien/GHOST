Quick reference for GHOST's core concepts. Each links to its detailed chapter.

<CardGrid>
  <Card title="OPERATOR">
    The human user. One per installation. Identified by Discord user ID.
  </Card>
  <Card title="GHOST">
    The AI agent. Identity defined by workspace files. One per installation.
  </Card>
  <Card title="Identity">
    BOOT.md, SOUL.md, OPERATOR.md — files that define your GHOST's personality and your
    preferences. [Learn more →](/ghost/identity/)
  </Card>
  <Card title="Provider">
    LLM backend (OpenRouter, Kimi Code, OpenAI OAuth). Configurable model aliases.
    [Learn more →](/ghost/providers/)
  </Card>
  <Card title="Interface">
    Communication transport. Discord is the primary interface. [Learn more
    →](/ghost/interfaces/)
  </Card>
  <Card title="Session">
    A chat thread between OPERATOR and GHOST. Maps 1:1 to a Discord thread. [Learn more
    →](/features/chat/)
  </Card>
  <Card title="Knowledge">
    Notes, references, and diary entries stored in SurrealDB with graph edges and
    embeddings. [Learn more →](/features/knowledge/)
  </Card>
  <Card title="Skill">
    Workflow file (agentskills.io format) that teaches your GHOST how to handle specific
    tasks. [Learn more →](/features/skills/)
  </Card>
  <Card title="Agent">
    Autonomous background worker for complex multi-step tasks (research, reflection).
    [Learn more →](/features/agents/)
  </Card>
  <Card title="Job">
    Cron-scheduled markdown file that runs on a timer. [Learn more →](/features/jobs/)
  </Card>
  <Card title="Tool">
    A capability the GHOST can invoke during chat (file I/O, search, web fetch, etc.).
    [Learn more →](/features/tools-core/)
  </Card>
</CardGrid>
