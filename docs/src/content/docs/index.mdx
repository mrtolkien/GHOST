<div class="ghost-features">

<div>

### Plain text workspace

Identity, skills, agents, knowledge — editable files in `~/GHOST/`.

Edit markdown to change behavior.

Drop a file to add a workflow.

`git diff` your GHOST.

</div>

<div>

### Knowledge graph

`[[from>wiki links]]` typed edges between notes.

Archived web sources with typed citations.

Daily diary.

Hybrid BM25 + embedding search.

Reflection agents extract knowledge from idle conversations — your GHOST learns
while you sleep.

</div>

<div>

### Lua agents

Background workers — cron, idle triggers, or spawned by other agents.

Restricted tools, own system prompts, discovered through skills.

Run tools automatically before hitting a model for deterministic behavior.

Ships with **deep-research** and **chat-reflection**.

Write yours — it's a file in `agents/`.

</div>
<div>

### GHOST HACK

Just ask and the Puppet Master takes over your channel.

A coding agent inspired by pi-mono.

Loads project rules, repo-local skills, and agents automatically.

Reads code, asks questions, runs tests, commits.

`/kill` when done.

</div>

<div>

### Token efficiency

Minimal tools. Miminal prompt. Minimal context.

Everything is built with the goal of spending as few tokens as possible.

Why use many tokens when few do trick?

</div>
