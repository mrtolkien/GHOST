## Philosophy

<CardGrid>
  <Card title="Text-first" icon="document">
    Workspace files (markdown, TOML) are the primary feature surface. Identity, skills,
    jobs, and knowledge all live as editable files.
  </Card>
  <Card title="CLI-first" icon="forward-slash">
    Every feature is accessible through direct commands.
  </Card>
  <Card title="Skills over tools" icon="puzzle">
    Prefer reusable workflow files over adding new tool APIs.
  </Card>
  <Card title="Local-first" icon="laptop">
    Embedded database, local embeddings, your data stays on your machine.
  </Card>
</CardGrid>

## Architecture

<table>
  <thead>
    <tr>
      <th colspan="3" style="text-align: center;">ghost daemon</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Discord Bot</td>
      <td>Job Scheduler</td>
      <td>Chat Orchestration</td>
    </tr>
    <tr>
      <td colspan="3" style="text-align: center;">Provider Layer (OpenRouter, Kimi, Codex)</td>
    </tr>
    <tr>
      <td colspan="2">SQLite + sqlite-vec</td>
      <td>Workspace Files</td>
    </tr>
  </tbody>
</table>

- **Single binary** — no external services required (except Ollama for embeddings)
- **Embedded SQLite** — knowledge storage with FTS5, sqlite-vec embeddings, and typed edges
- **Discord transport** — primary interface for the PoC (more planned)
- **Multiple LLM providers** — OpenRouter, Kimi Code, OpenAI OAuth (Codex)
